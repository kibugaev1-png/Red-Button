# Красная кнопка — правила работы над проектом

## Главный репозиторий

**https://github.com/kibugaev1-png/Red-Button**

Это единственный основной репозиторий проекта. Ветка — `main`, remote — `origin`.
Всё, что сделано локально, должно оказаться там.

## Коммитить и пушить постоянно

Репозиторий обязан всегда отражать текущее состояние игры. Правило простое:

1. **Закончил осмысленный кусок работы — сразу коммит.** Не копи изменения
   на весь день: починил баг, добавил механику, поправил графику — коммит.
2. **После коммита сразу `git push origin main`.** Локальный коммит без пуша
   репозиторий актуальным не делает.
3. **Перед тем как начать новую задачу — проверь, что дерево чистое**
   (`git status`). Если остались незакоммиченные правки — закоммить их.
4. **Сообщение коммита — на русском, по делу:** что изменилось и зачем.
   «Зомби больше не прыгают с этажей» лучше, чем «fix bugs».
5. **Ничего не push --force в `main`.** История нужна для откатов.

Быстрый путь: двойной клик по **«Отправить на GitHub.command»** — он делает
коммит всех изменений и пуш одной операцией.

## Что не попадает в репозиторий

Смотри `.gitignore`. Коротко: собранное приложение `Красная кнопка.app` и папка
`build/` — артефакты, пересобираются скриптом.

А вот **«Красная кнопка v2.html» в репозитории нужна** — это игра одним файлом,
её отправляют другу и её же отдаёт GitHub Pages. После правок в `js/` её надо
пересобирать, иначе она отстанет от исходников.

## Структура проекта

| Путь | Что это |
|---|---|
| `index.html` | точка входа игры, подключает модули |
| `js/*.js` | сама игра: мир, игрок, зомби, строительство, интерфейс |
| `app/` | исходники нативного приложения macOS на Swift |
| `serve.py` | локальный сервер игры, порт 4986 |
| `Красная кнопка v2.html` | вся игра одним файлом, для отправки и для Pages |
| `docs/superpowers/specs/` | дизайн-документ |
| `*.command` | скрипты в один клик: сборка, бэкап, откат, сервер, пуш |

## Проверка перед пушем

Игра не должна падать. Минимум: открыть локально, начать новую игру,
прогнать пару минут. Синтаксис всех модулей проверяется так:

```bash
node -e "const fs=require('fs'); for (const f of ['core','world','human','items','player','entities','build','boom','ui','game']) new Function(fs.readFileSync('js/'+f+'.js','utf8')); console.log('синтаксис ок')"
```
