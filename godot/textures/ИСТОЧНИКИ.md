# Откуда текстуры

Все текстуры — с [ambientCG](https://ambientcg.com), лицензия **CC0** (общественное
достояние). Их можно свободно использовать в игре, продавать игру и выкладывать
её куда угодно; указывать автора не обязательно, но мы указываем.

| Файл | Исходный набор |
|---|---|
| `grass_*` | Grass004 |
| `dirt_*` | Ground037 |
| `clay_*` | Ground054 |
| `gravel_*` | Ground068 |
| `rock_*` | Rock030 |
| `concrete_*` | Concrete034 |
| `wood_*` | Planks011 |
| `bark_*` | Bark012 |
| `metal_*` | Metal032 |

Из каждого набора взяты только две карты: `_color` (цвет) и `_normal` (рельеф,
вариант NormalGL). Скачивались версии 1K-JPG, затем сжаты до 512×512 — на
частицах в 8 пикселей большего разрешения не видно, а вес падает в разы.

Как добавить новую породу:

1. Скачать набор с ambientCG, взять `_Color.jpg` и `_NormalGL.jpg`.
2. Привести к строго 512×512 (важно: `Texture2DArray` требует одинаковых
   размеров, поэтому `sips -z 512 512`, а не `-Z 512`).
3. Положить как `<имя>_color.jpg` и `<имя>_normal.jpg`.
4. Добавить `<имя>` в `TEX_LAYERS` в `scripts/terrain.gd` и сослаться на слой
   в `_layer_for()`.
